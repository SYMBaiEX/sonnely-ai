# Sonnely homepage design brief

Keep the homepage hero, its seasonal scene, and the interactive request path intact. Give each section below the hero a clear job and enough space to read at a glance.

- Make the API example a workbench. Put the code and its response side by side when there is room. Keep language selection, copying, and JSON output usable on phones.
- Group the integration links into a compact strip. Lead the gateway section with the provider route and use smaller panels for the endpoint, budgets, and funding.
- Keep every model, its privacy route, context window, and token rates visible. Follow the comparison with three readable task examples.
- Make the workspace preview interactive. Let visitors explore API keys, usage, and funding through keyboard-accessible tabs.
- Use self-contained links for the platform directory, a featured guide with two supporting articles, and a native FAQ accordion. End with a clear console action, SDK access, and a spacious footer.
- Use warm surfaces and layered artwork in dark mode. Use cool paper surfaces, outlined model rows, and inset artwork in light mode. Keep the information and focus order consistent.
- Use a recessed sun–moon slider with an illuminated thumb, a warm daylight glow, and a rose moonlight glow. Share it across the site, console, and docs.

Registry patterns explored on 21st.dev include Code Block, Minimal Logo Kicker Strip, Feature Bento, Table, Icon Link Card, Vertical Tabs, Documentation Link Card, Accordion, Gradient CTA Banner, and Sliding Icon Theme Switch. Adapt these patterns using Sonnely’s existing primitives, content, typography, and assets.
