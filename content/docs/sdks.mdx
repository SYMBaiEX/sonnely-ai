## TypeScript or JavaScript

Install the first-party server-side package with Node.js 22.12 or newer. Registry releases are available on [npm](https://www.npmjs.com/package/@sonnely/sdk).

```bash title="Terminal · Install the TypeScript SDK"
npm install https://sonnely.com/sdk/sonnely-typescript-0.1.5.tgz
```

A [versioned npm archive](https://sonnely.com/sdk/sonnely-typescript-0.1.5.tgz) is also available from Sonnely. Save the example in the folder where you installed the package. Run `node complete.mjs` or `node stream.mjs`.

<Tabs className="docs-example-tabs" items={["Completion", "Streaming"]}>
<Tab value="Completion">

```javascript title="complete.mjs"
import { Sonnely } from "@sonnely/sdk";

const sonnely = new Sonnely({ apiKey: process.env.SONNELY_API_KEY });
const request = {
  model: "deepseek-ai/DeepSeek-V4.1-Flash-1017",
  messages: [{ role: "user", content: "Write one line about a forest." }],
  max_tokens: 128,
};

const result = await sonnely.complete(request);
console.log(result.choices[0]?.message.content);
console.log(result.usage);
```

</Tab>
<Tab value="Streaming">

```javascript title="stream.mjs"
import { Sonnely } from "@sonnely/sdk";

const sonnely = new Sonnely({ apiKey: process.env.SONNELY_API_KEY });
const request = {
  model: "deepseek-ai/DeepSeek-V4.1-Flash-1017",
  messages: [{ role: "user", content: "Write one line about a forest." }],
  max_tokens: 128,
};

for await (const chunk of sonnely.stream(request)) {
  process.stdout.write(chunk.choices[0]?.delta.content ?? "");
  if (chunk.usage) console.log("\n", chunk.usage);
}
```

## Python

Use Python 3.11 or newer with the first-party [PyPI package](https://pypi.org/project/sonnely-sdk/). Check `python3 --version` first. If it shows an older version, use a newer interpreter to create the environment.

On macOS or Linux, run these commands from your project folder. If you already have a virtual environment, activate it and run the install command. See the [Python activation commands](https://docs.python.org/3/library/venv.html#how-venvs-work) for other shells.

```bash title="Terminal · Install the Python SDK"
python3 -m venv .venv
source .venv/bin/activate
python -m pip install https://sonnely.com/sdk/sonnely_sdk-0.1.5-py3-none-any.whl
```

Follow [Quickstart](/docs/quickstart#set-up-your-workspace) to set `SONNELY_API_KEY` in the same terminal. Save the snippet as `complete.py` or `stream.py`, then run `python complete.py` or `python stream.py` with the environment still active. A [versioned wheel](https://sonnely.com/sdk/sonnely_sdk-0.1.5-py3-none-any.whl) is also available.

> **If the example stops before sending a request**, `ModuleNotFoundError: No module named 'sonnely'` means the Python running the script cannot find the package. Activate the environment and rerun the install command. For `KeyError: 'SONNELY_API_KEY'`, set the key in that terminal.

<Tabs className="docs-example-tabs" items={["Completion", "Streaming"]}>
<Tab value="Completion">

```python title="complete.py"
import os
from sonnely import Sonnely

sonnely = Sonnely(api_key=os.environ["SONNELY_API_KEY"])
request = {
    "model": "deepseek-ai/DeepSeek-V4.1-Flash-1017",
    "messages": [{"role": "user", "content": "Write one line about a forest."}],
    "max_tokens": 128,
}

result = sonnely.complete(request)
print(result["choices"][0]["message"]["content"])
print(result["usage"])
```

</Tab>
<Tab value="Streaming">

```python title="stream.py"
import os
from sonnely import Sonnely

sonnely = Sonnely(api_key=os.environ["SONNELY_API_KEY"])
request = {
    "model": "deepseek-ai/DeepSeek-V4.1-Flash-1017",
    "messages": [{"role": "user", "content": "Write one line about a forest."}],
    "max_tokens": 128,
}

for chunk in sonnely.stream(request):
    for choice in chunk.get("choices", []):
        print(choice["delta"].get("content") or "", end="", flush=True)
    if chunk.get("usage"):
        print("\n", chunk["usage"])
```

</Tab>
</Tabs>

The streaming example prints text as it arrives, then prints the final usage counts. That usage chunk has an empty `choices` array, so the code checks `usage` outside the loop over choices.

> **Streaming confirms settlement.** Both clients request final usage by default, surface stream errors, and require `[DONE]` before ending normally.

Find the final charge in [Request logs](/console/logs) using the request reference. The detail panel shows both token counts and the settled dollar charge.

Both clients also provide public `models()`, per-request ceilings through `max_cost_microusd`, and optional [completion receipts](/docs/attestation#completion-receipts).

## Request IDs and retries

SDK 0.1.5 accepts an idempotency key on both completion methods. Use one key per logical operation, and reuse it when retrying that operation. Each SDK call sends a single request and leaves retry decisions to your code.

The gateway returns HTTP 409 if the key already started a request. Read the original request ID from the error and look it up in [Request logs](/console/logs). HTTP and stream errors expose the request ID and any `Retry-After` header returned by the gateway.

| SDK | Idempotency option | Error fields | Response callback |
| --- | --- | --- | --- |
| TypeScript | `idempotencyKey` | `status`, `requestId`, `retryAfter` | `onResponse({ requestId, retryAfter })` |
| Python | `idempotency_key` | `status`, `request_id`, `retry_after` | `on_response(metadata)` with `metadata.request_id` and `metadata.retry_after` |

Responses from `complete` include the gateway’s `sonnely_request_id` field. Pass the response callback to capture the reference when a stream opens. The completion’s `id` remains the provider’s completion ID.

## Existing OpenAI SDKs

Keep your current SDK and set its base URL to `https://sonnely.com/api/sonnely/v1` and API key to your Sonnely key. Use Chat Completions and a Sonnely model ID. The examples below use the base `openai` packages and disable automatic retries for billable calls.

<Tabs className="docs-example-tabs" items={["JavaScript", "Python"]}>
<Tab value="JavaScript">

Install with `npm install openai`.

```javascript title="complete.mjs"
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.SONNELY_API_KEY,
  baseURL: "https://sonnely.com/api/sonnely/v1",
  maxRetries: 0,
});
const completion = await client.chat.completions.create({
  model: "deepseek-ai/DeepSeek-V4.1-Flash-1017",
  messages: [{ role: "user", content: "Describe a forest village." }],
  max_tokens: 128,
});
console.log(completion.choices[0]?.message.content);
```

</Tab>
<Tab value="Python">

Install with `python -m pip install openai`.

```python title="complete.py"
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["SONNELY_API_KEY"],
    base_url="https://sonnely.com/api/sonnely/v1",
    max_retries=0,

completion = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V4.1-Flash-1017",
    messages=[{"role": "user", "content": "Describe a forest village."}],
    max_tokens=128,
)
print(completion.choices[0].message.content)
```

## Specialized inference

SDK 0.1.3 adds `infer` for Responses, redaction, document conversion, audio, embeddings, reranking, images, and System One. Choose a model and fields from [Models and rates](/docs/providers#embeddings-decisions-images-and-audio). Responses include the [usage reference](/docs/observability) alongside the result. Call `providerModels()` in TypeScript or `provider_models()` in Python for the full provider inventories.

```typescript
const { data, requestId } = await sonnely.infer<{ redacted_text: string }>("redact", {
  model: "pii-filter",
  text: "Contact the sample customer at alice@example.com.",
  max_cost_microusd: 2000,
});
console.log(data.redacted_text, requestId);
```

```python
output, request_id = sonnely.infer(
    "convert/file",
    {"model": "doc-upload", "max_cost_microusd": 55000},
    file="sample.pdf",
)
print(output["document"]["md_content"], request_id)
```

Use a `FormData` body in TypeScript for file endpoints. Send `model` and the documented file field, for example `files` for PDF conversion or `file` for audio. Python sets the field from the endpoint. Speech synthesis returns an `ArrayBuffer` in TypeScript and `bytes` in Python. For request retries, pass `idempotencyKey` in the TypeScript options or `idempotency_key` as a Python keyword argument.

## Realtime transcription

The SDKs return the URL and bearer headers for a server-side WebSocket client. Wait for `session.created` before sending audio, and wait for `transcription.done` before treating it as settled. Follow the [realtime protocol](/docs/providers#additional-tinfoil-endpoints) for audio limits and events.

```typescript
import WebSocket from "ws";

const { url, headers } = sonnely.realtimeConnection();
const socket = new WebSocket(url, { headers, followRedirects: false });
```

```python
from websockets.sync.client import connect

url, headers = sonnely.realtime_connection()
with connect(url, additional_headers=headers) as socket:
    print(socket.recv())
    # Stream PCM16 chunks while the connection is open.
```
