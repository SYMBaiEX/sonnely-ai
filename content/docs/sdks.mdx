Use a key from a workspace with credits. Follow [Quickstart](/docs/quickstart#set-up-your-workspace) to create the key and set `SONNELY_API_KEY` in the terminal where you’ll run the examples. Choose either **Completion** or **Streaming** below. Each run sends one billable request.

## TypeScript or JavaScript

Install the first-party server-side package from [npm](https://www.npmjs.com/package/@sonnely/sdk) with Node.js 22 or newer.

```bash title="Terminal · Install the TypeScript SDK"
npm install @sonnely/sdk
```

A [versioned npm archive](https://sonnely.com/sdk/sonnely-typescript-0.1.2.tgz) is also available from Sonnely. Save the example in the folder where you installed the package. Run `node complete.mjs` or `node stream.mjs`.

<Tabs className="docs-example-tabs" items={["Completion", "Streaming"]}>
<Tab value="Completion">

```javascript title="complete.mjs"
import { Sonnely } from "@sonnely/sdk";

const sonnely = new Sonnely({ apiKey: process.env.SONNELY_API_KEY });
const request = {
  model: "deepseek-ai/DeepSeek-V4.1-Flash-1017",
  messages: [{ role: "user", content: "Write one line about a forest." }],
  max_tokens: 128,
};

const result = await sonnely.complete(request);
console.log(result.choices[0]?.message.content);
console.log(result.usage);
```

</Tab>
<Tab value="Streaming">

```javascript title="stream.mjs"
import { Sonnely } from "@sonnely/sdk";

const sonnely = new Sonnely({ apiKey: process.env.SONNELY_API_KEY });
const request = {
  model: "deepseek-ai/DeepSeek-V4.1-Flash-1017",
  messages: [{ role: "user", content: "Write one line about a forest." }],
  max_tokens: 128,
};

for await (const chunk of sonnely.stream(request)) {
  process.stdout.write(chunk.choices[0]?.delta.content ?? "");
  if (chunk.usage) console.log("\n", chunk.usage);
}
```

</Tab>
</Tabs>

## Python

Install the first-party client from [PyPI](https://pypi.org/project/sonnely-sdk/) with Python 3.10 or newer.

```bash title="Terminal · Install the Python SDK"
python -m pip install sonnely-sdk
```

A [versioned wheel](https://sonnely.com/sdk/sonnely_sdk-0.1.2-py3-none-any.whl) is also available from Sonnely. Use the same Python environment you installed into. Run `python complete.py` or `python stream.py`.

<Tabs className="docs-example-tabs" items={["Completion", "Streaming"]}>
<Tab value="Completion">

```python title="complete.py"
import os
from sonnely import Sonnely

sonnely = Sonnely(api_key=os.environ["SONNELY_API_KEY"])
request = {
    "model": "deepseek-ai/DeepSeek-V4.1-Flash-1017",
    "messages": [{"role": "user", "content": "Write one line about a forest."}],
    "max_tokens": 128,
}

result = sonnely.complete(request)
print(result["choices"][0]["message"]["content"])
print(result["usage"])
```

</Tab>
<Tab value="Streaming">

```python title="stream.py"
import os
from sonnely import Sonnely

sonnely = Sonnely(api_key=os.environ["SONNELY_API_KEY"])
request = {
    "model": "deepseek-ai/DeepSeek-V4.1-Flash-1017",
    "messages": [{"role": "user", "content": "Write one line about a forest."}],
    "max_tokens": 128,
}

for chunk in sonnely.stream(request):
    for choice in chunk.get("choices", []):
        print(choice["delta"].get("content") or "", end="", flush=True)
    if chunk.get("usage"):
        print("\n", chunk["usage"])
```

</Tab>
</Tabs>

> **Streaming confirms settlement.** Both clients request final usage by default, surface stream errors, and require `[DONE]` before ending normally.

Find the final charge under **Recent requests** in [Usage](/console/usage). The token counts printed by the examples are separate from the dollar amount charged there.

Both clients also provide public `models()`, route pinning through `provider.only`, per-request ceilings through `max_cost_microusd`, and optional [completion receipts](/docs/attestation#completion-receipts).

## Existing OpenAI SDKs

Keep your current SDK and set its base URL to `https://sonnely.com/api/sonnely/v1` and API key to your Sonnely key. Use Chat Completions and a Sonnely model ID. The examples below use the base `openai` packages and disable automatic retries for billable calls.

<Tabs className="docs-example-tabs" items={["JavaScript", "Python"]}>
<Tab value="JavaScript">

Install with `npm install openai`.

```javascript title="complete.mjs"
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.SONNELY_API_KEY,
  baseURL: "https://sonnely.com/api/sonnely/v1",
  maxRetries: 0,
});
const completion = await client.chat.completions.create({
  model: "deepseek-ai/DeepSeek-V4.1-Flash-1017",
  messages: [{ role: "user", content: "Describe a forest village." }],
  max_tokens: 128,
});
console.log(completion.choices[0]?.message.content);
```

</Tab>
<Tab value="Python">

Install with `python -m pip install openai`.

```python title="complete.py"
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["SONNELY_API_KEY"],
    base_url="https://sonnely.com/api/sonnely/v1",
    max_retries=0,
)
completion = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V4.1-Flash-1017",
    messages=[{"role": "user", "content": "Describe a forest village."}],
    max_tokens=128,
)
print(completion.choices[0].message.content)
```

</Tab>
</Tabs>

Use the [OpenAPI spec](/api/openapi) or the [cURL quickstart](/docs/quickstart) for other runtimes.
