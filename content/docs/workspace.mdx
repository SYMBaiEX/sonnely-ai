## Wallet and profile

Connect a Solana wallet in the console and approve the sign-in message. Your active wallet is shown in the header. To switch workspaces, open the wallet menu, sign out, then connect the other wallet.

> **Wallet approvals.** Sign-in uses a wallet signature. Sending USDC or SOL requires a separate approval in Billing.

In [Settings](/console/settings), set a display name and an optional username. Usernames use 3–24 letters, numbers, or underscores and start with a letter. Sonnely normalizes usernames to lowercase. Your username can appear in referral activity.

## Invite a user

Copy your personal invite link from [Referrals](/console/referrals). The pipeline shows attributed sign-ups, mainnet funding, and paid inference. Use these activity states to track adoption.

## Browser and account data

<div className="docs-guide-facts">

- **This browser.** Choose **Save chats on this device** to keep conversations across refreshes. Playground reopens your selected conversation, and Settings lets you manage or clear saved chats.
- **Across devices.** Sign in with the same wallet to see your usage and credits.

</div>

## Support requests

Open [Support](/console/support) to start a request or follow an existing thread. New requests need an email, a topic, and a message, and each signed-in wallet can open up to five requests per day.

Expand a request to read the conversation and reply. A **New reply** badge marks threads where the team answered since you last opened them. Replying to a resolved request reopens it so it re-enters the queue.
