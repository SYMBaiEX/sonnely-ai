Dry Docks builds a pinned public GitHub commit in a temporary Boat Linux VM.

## Planned workflow

1. Enter a public repository and full commit SHA.
2. Review the build window and credit quote.
3. Follow output from `npm ci` and `npm run build`.
4. Download the first matching output directory from `dist`, `build`, `out`, or `.next`. The archive limit is 5 MiB.

The planned build VM receives no user credentials and has no inbound endpoint. Sonnely requests deletion after stopping the run and settles the receipt after deletion is confirmed. Logs and artifacts are intended to expire after seven days. Check the [Dry Docks product page](/dry-docks) for availability.
