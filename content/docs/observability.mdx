## Inspect usage

Open [Usage](/console/usage) and choose a UTC date range. Switch between spend, tokens, and request counts. Group by model or API key to identify activity. The balance may include fractions of a cent, so use the displayed precision when comparing small requests.

## Export to UsageMax

Export up to 100 settled inference requests from the selected period. Download a telemetry batch or send it using an advanced write-only UsageMax collector key. Reuse the same installation UUID for consistent deduplication. The export includes model, provider, timestamps, token counts and ledger charges. Store collector credentials in UsageMax or your secret manager. [UsageMax collector documentation](https://usagemax.com/docs)

## Platform reconciliation

Authorized Sonnely operators can inspect request spans, provider attempts, evidence checks, holds and final settlements in Admin. NEAR per-request cost lookups run on a schedule. Finalized invoice exports can be imported separately and matched against provider billing references. Reconciliation can revise the provider cost record without changing the customer charge. Treasury payout approval and wallet signing are manual.

Alerts can be delivered through the configured operations inbox. Admin reports delivery status, unmatched fees, open holds and truncated report coverage. [Explore the observability product page](/observability)
