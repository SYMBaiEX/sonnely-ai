## Inspect usage

Open [Usage](/console/usage) and choose a UTC date range. Group by model or API key to identify activity.

- **Spend** shows what settled requests charged. Use the displayed precision when comparing fractions of a cent.
- **Tokens** shows the volume billed over the period.
- **Requests** counts activity for the selected period.

## Export to UsageMax

Export up to 100 settled inference requests from the selected period. A batch contains model, provider, timestamps, token counts, and ledger charges.

- **Download a batch** to import it yourself.
- **Send to a collector** with a write-only UsageMax key. Reuse the installation UUID for deduplication and store collector credentials in UsageMax or your secret manager.

[UsageMax collector documentation](https://usagemax.com/docs)

## Platform reconciliation

Authorized Sonnely operators can inspect request spans, provider attempts, evidence checks, holds and final settlements in Admin. NEAR per-request cost lookups run on a schedule. Finalized invoice exports can be imported separately and matched against provider billing references. Reconciliation can revise the provider cost record without changing the customer charge. Treasury payout approval and wallet signing are manual.

Alerts can be delivered through the configured operations inbox. Admin reports delivery status, unmatched fees, open holds and truncated report coverage. [Explore the observability product page](/observability)
