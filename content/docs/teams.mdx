---
title: Teams and projects
description: Invite a wallet, limit project spending, and issue scoped API keys.
---

Open [Teams](/console/teams) with your Solana wallet connected. Create a team and a project to give an application its own keys and spending budget.

## Add members

An owner or admin can invite a Solana wallet address. The invitation appears in Teams after the recipient signs in with that exact wallet. It expires after seven days. Owners can appoint admins, change roles, and remove members. Admins can invite or remove members. Members can read the team roster, project budgets, and recent project requests.

## Control project spending

Project requests draw credits from the team owner’s account. Owners and admins can set a lifetime project budget and issue project keys with optional daily caps, lifetime caps, and expiration dates. A request must fit the project budget, its key caps, and the balance available to the owner. The budget panel includes both final charges and current reservations. Released reservations return to the project budget and the owner’s balance.

Copy the project key when you create it. Use it as the bearer token on the [Sonnely API](/docs/api). Use a project key for workloads you want billed to that project. Wallet sign-in alone uses your personal console balance.

Archiving a project or revoking a key blocks new requests. Reservations already in progress can still settle. An admin’s keys and pending invitations expire when the admin leaves, is removed, or becomes a member. The owner can issue keys for workloads that should outlive a particular admin’s access.

## Find project activity

Choose a team and a project to see its budget and the latest 30 request references. Team membership grants access to those project records. The owner’s personal keys and balance are accessible through their own wallet session.
