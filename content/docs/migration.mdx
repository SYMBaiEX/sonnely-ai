## Move your integration

Update the base URL, API key, and model ID together. Check the streamed and non-streamed paths before switching traffic.

<div className="docs-guide-procedure">

1. **Sign in.** Open the [current Sonnely console](/console) and connect a Solana wallet.
2. **Create credentials.** Create a [Sonnely API key](/console/keys) and add [credits](/docs/billing).
3. **Point your client at Sonnely.** Set your OpenAI-compatible client’s base URL to `https://sonnely.com/api/sonnely/v1` and choose an ID from [model discovery](/api/sonnely/v1/models).
4. **Check your requests.** Switch to text Chat Completions. Check your app’s streamed and non-streamed calls against the [current contract](/docs/api).

</div>

> **Compatibility.** Existing inference integrations using `/v1` can migrate at their own pace. The original app’s media APIs and CLI are retired.
