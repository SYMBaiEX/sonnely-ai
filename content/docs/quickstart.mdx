## Set up your workspace

1. **Connect your wallet.** Open the [console](/console), choose **Set up your workspace**, and connect a Solana wallet. On mobile, use your wallet’s browser or Chrome on Solana Seeker. You can try a built-in sample before funding.
2. **Add credits.** Accept the current terms, set a display name if you like, and follow the [funding guide](/docs/billing) to add Solana USDC in Billing.
3. **Create an API key.** Open [API keys](/console/keys), create a key, and copy it when it appears. Set it as the `SONNELY_API_KEY` environment variable in the shell where you’ll run the example.

> **Keep your key server-side.** In an app, load it from your server’s environment or secret manager.

</Step>
<Step>

## Find a model ID

This endpoint is public. Use an exact model ID from the response. Each entry shows the available provider routes and their rates.

```bash title="Terminal · List available models"
curl -fsS https://sonnely.com/api/sonnely/v1/models
```

</Step>
<Step>

## Send a completion

This example sends one billable request. If you choose another model from discovery, replace the model ID before running it.

```bash title="Terminal · Send a text completion"
curl -sS --fail-with-body https://sonnely.com/api/sonnely/v1/chat/completions \
  -H "Authorization: Bearer ${SONNELY_API_KEY:?Set SONNELY_API_KEY first}" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "deepseek-ai/DeepSeek-V4.1-Flash-1017",
    "messages": [
      {"role": "user", "content": "Suggest one name for a snowy forest village."}
    ],
    "max_tokens": 128
  }'
```

</Step>
<Step>

## Read the result

- **Answer** is in `choices[0].message.content`.
- **Token counts** are in `usage`, including `prompt_tokens`, `completion_tokens`, and `total_tokens`.
- **Final charge and request status** appear in [Usage](/console/usage) after settlement.

</Step>
